# Sonsuz Nokta Koyma Makinesi

Bu repository, insanlığın en büyük sorununu çözmek için yaratılmıştır: **Sonsuza kadar nokta koymak.**

## Neden Bu Kadar Önemli?

Düşünün bir. Noktalar. Onlar olmadan cümleler biter mi? Hayır. Ama biz nokta koyarak bitiririz. Bu makine, sizin yerinize sonsuza kadar nokta koyarak dünyayı kurtarır. Gerçekten.

### Kullanım

```bash
python nokta_koy.py
```

Program çalıştığında ekrana sürekli "." koyar. Durdurmak için Ctrl+C yapın. Ama durdurmayın. Noktalar kızgın olur.

## Bilimsel Temel

Bu proje, “Nokta Teoremi” üzerine kuruludur. Teoreme göre, yeterince nokta koyarsanız bir şey olur. Ne olur? Bilmiyoruz. Ama olur. Kesinlikle.

### Özellikler
- Sonsuz döngü (ama kısa süreli, RAM bitene kadar)
- Rastgele "Nokta koyuldu!" mesajları
- Hiçbir işe yaramaz ama gurur duymanızı sağlar

## Katkıda Bulunma

PR açmayın. Noktalar zaten yeterince var. Sadece star atın ve uzaklaşın.
